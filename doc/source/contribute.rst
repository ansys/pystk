Contribute
##########

Thank you for your interest in contributing to PySTK! Contributions are welcome
to make the project better, whether it's fixing bugs, adding new features, or
improving documentation. Below are the guidelines to follow when contributing.

.. important::

    This project adheres to the `Contributor Covenant Code of Conduct`_. By
    participating, you agree to uphold this code.

You need a GitHub account to contribute to PySTK. Read the guidelines on
`signing up for a new GitHub account`_ so you can participate in the
project.

.. _signing up for a new GitHub account: https://docs.github.com/en/get-started/signing-up-for-github/signing-up-for-a-new-github-account

Start by selecting your role in the project:

    .. grid-item-card:: :fa:`user` User
        :link: contribute/user
        :link-type: doc
        :padding: 2 2 2 2

        Report bugs, suggest features, and ask questions.

    .. grid-item-card:: :fa:`book` Documentarian
        :link: contribute/documentarian
        :link-type: doc
        :padding: 2 2 2 2

        Improve the documentation and write new guides.

    .. grid-item-card:: :fa:`laptop-code` Developer
        :link: contribute/developer
        :link-type: doc
        :padding: 2 2 2 2

        Fix bugs, add new features, and improve the codebase.
